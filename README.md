# Stacy Barilone | Brand Ambassador & Event Host

Professional single-page website for Stacy Barilone.

**Live preview**: Open `index.html` in any modern browser (Tailwind via CDN — no build step needed).

## Design
- Deep Navy background (#0D1B2A)
- Rich Gold text & accents (#D4AF37)
- Professional Red trim used sparingly (#9C1F1F)
- Clean, premium, confident energy — never busy

## Key Sections
- Hero with strong personal branding
- About (highlights time management, reliability, public speaking, brand embodiment, vibrant energy)
- Approach & Signature Strengths
- Featured Experience (Indian Motorcycles at Laconia Bike Week, MINI World Cup activation, Motorcycle Club events with bands/DJs & full planning)
- Services
- Testimonials
- Contact / Inquiry form (demo success state — easy to wire to Formspree, Netlify Forms, etc.)

## How to Customize
1. Replace photos in the `images/` folder (keep exact filenames)
2. Edit copy directly in `index.html`
3. The site is fully self-contained

## Deployment (Recommended)
1. Push this repo to GitHub (done)
2. Connect the repo to Netlify (or Vercel)
3. Every push to `main` will auto-deploy

## Images
The three photos live in the `images/` folder. Drag & drop them into this repo on GitHub.com (GitHub supports folder drag-and-drop). Then update the image paths in `index.html` if needed (they're already set to `images/filename.jpg`).

## Tech
- Single HTML file
- Tailwind CSS via CDN
- Vanilla JS for mobile menu, smooth scroll, form handling
- Fully responsive
